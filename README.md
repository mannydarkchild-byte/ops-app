# OPS | Equipment Operations & Shift Verification Platform

> **One machine. One shift. One verified record.** Built for the people on the machine and the people who answer for it.

OPS is a dispute-proof, offline-first equipment operations and shift verification platform engineered specifically for **plant hire companies, contract crushing and screening, open-cast mining contractors, and civil earthmoving fleets**.

---

## 🚀 Commercial Product Overview

In heavy machinery operations, contractors and hire firms lose an estimated **5% to 15% of billable revenue** due to month-end invoice disputes over unverified downtime, lost paper timesheets, and contested machine hour meters.

OPS eliminates disputes before invoices are generated by establishing a tamper-proof digital chain of custody from the machine cab to executive management:

1. **Pre-Start Safety Inspection:** Guided walkaround checks per machine type with photo defect capture and voice-to-text logging.
2. **Physical Hour Meter Verification:** Opening and closing physical hour meter photos locked directly to each shift.
3. **Contractual Downtime Attribution:** Every stoppage is categorized with duration, cause, and responsible owner (*Contractor Mechanical* vs *Consumables & Wear* vs *Client Site Delays*).
4. **Supervisor Digital Sign-Off:** The client site representative reviews and signs the digital shift card on-site every afternoon.
5. **100% Offline-First (PWA):** Zero cellular reception required in deep pits or remote quarries; automatically synchronizes when connection is restored.
6. **Maintenance & Storeroom Loop:** Operator-reported defects automatically generate mechanic work orders and deduct required parts from storeroom stock.
7. **Automated WhatsApp Dispatch:** Instant end-of-shift executive summaries dispatched to management WhatsApp groups.

## 🛠️ Technology Stack & Architecture

- **Frontend:** React 19, Vite 8, React Router 7, Tailwind CSS
- **Offline Storage:** Dexie (IndexedDB) for local-first zero-latency field operations
- **Sync Engine:** Custom two-way push/pull synchronization with conflict resolution
- **Backend & Auth:** Supabase (PostgreSQL, Row-Level Security, Storage Buckets)
- **Field UX Tools:** Voice-to-text (`react-speech-recognition`), Signature Pad, Canvas media compression
- **Document & Export Services:** `html2pdf.js`, `xlsx` (Excel), WhatsApp API dispatch
- **Hosting & Edge:** Vercel with single-page application routing (`vercel.json`)
- **Code Quality:** Oxlint (`.oxlintrc.json`)

## 🏃 Getting Started

### Prerequisites
- Node.js 18+
- npm or pnpm
- Supabase account & project

### Development Setup

```bash
# Clone the repository
git clone <repo-url>
cd ops-app

# Install dependencies
npm install

# Configure environment variables (.env.local)
VITE_SUPABASE_URL=your-supabase-url
VITE_SUPABASE_ANON_KEY=your-supabase-anon-key
VITE_DEMO_EMAIL=operations@yourcompany.com

# Start development server
npm run dev
```

### Production Build & Linting

```bash
# Run Oxlint
npm run lint

# Build for production
npm run build

# Preview build locally
npm run preview
```
